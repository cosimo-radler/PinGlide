# Elsewhere

See more. Click less.

## Identity

An image-first introduction to a Pinterest gallery extension, by Serif. Manrope is used for interface text, Instrument Serif for the wordmark. The extension itself retains the PinGlide name. Dark, solid surfaces keep the focus on imagery. The cobalt footer uses an oversized ivory wordmark and a slowly turning lime asterisk.

## Voice

Short, functional labels: Browse, Capture, Open. Each scroll phase has one heading and one short explanation. The Chrome extension link remains visible below the controls. No numbered eyebrows, extra captions, pricing, urgency or feature lists.

## Imagery

The 26-image collection combines nine user-selected works, eleven CC0 museum works and six original AI-created images, including three Elsewhere posters. See IMAGE-CREDITS.md. Every load shuffles the order and includes a branded poster in the first three images. GIFs remain animated with still fallbacks for reduced motion. Cards use the same level triptych arrangement and 22px corners, or 17px on mobile.

## Motion and interaction

The entrance holds the wordmark, then lands the image panels once. Scroll enlarges the centre image into the working gallery. Upward scrolling reverses the transition. Downward scrolling carries the gallery controls into a sticky walkthrough. Browse, Capture and Open become active in sequence while the cards stay in place. Arrow controls browse real images; M saves locally; Enter opens the original source. The demo uses original artworks, not a live Pinterest embed. The installed extension opens actual Pins. The Capture control becomes a checkmark after saving and opens the collection when clicked again. Reduced-motion preferences bypass the entrance and control travel.

## Boundaries

Capture stores known image references in this browser with a session fallback. No external service, account, analytics or checkout is connected. The Chrome extension link opens the existing project; header Install explains manual unpacked installation. Website edits do not change extension source.

A separate full-width black keyboard reference follows the image walkthrough, with large arrow / Enter / Esc keys and Browse / Open / Return labels underneath.
